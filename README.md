# The Daily Catch — playable copy

A harbour seafood kitchen game: one cook, a 150-second lunch rush.
Fetch ingredients, chop, grill, fry, plate and serve before the tickets time out.

**Play:** https://madinzgod.github.io/daily-catch-play/

Controls: WASD / arrow keys or click-to-walk, SPACE/E to interact.
